# Account deletion

<!-- intents: delete_account -->

## Start a request

Request account deletion from your signed-in privacy settings. Support reviews requests within 7 working days.

General policy applies across the fictional KharidiKart store. Check My Orders for details tied to a particular purchase. The demo displays order information only after selecting the account that owns the order.

Check account history before opening the deletion request. Save the invoices and refund references you may need later. Start the request from signed-in privacy settings so support can confirm which profile it concerns. If the request was accidental, update the existing case while the review is still open.

## Open orders

Wait for open orders and refunds to finish before requesting deletion. Keep order references for your records.

Use the account portal for a self-service change when the option is available. When contacting support about an existing purchase, keep the order reference handy and describe the outcome you need in a short message.

An order or refund in progress can require account access while delivery, return or payment matters are being resolved. Wait for those records to settle and check the account again. If a record stays pending longer than expected, use its reference to contact support before resuming deletion.

## Retention

Transaction records required for accounting may be retained for up to 8 years after account deletion.


Deletion affects access to the account and ordinary profile settings. The retention period for transaction records serves accounting obligations. If you need a copy of personal data, use the copy request option before closing the account. Keep any receipts you are required to retain for your own records.
