# Returns and exchanges

<!-- intents: check_refund_policy -->

## Return window

Start an eligible return within 7 calendar days of delivery. Keep the order ID and explain the reason.

General policy applies across the fictional KharidiKart store. Check My Orders for details tied to a particular purchase. The demo displays order information only after selecting the account that owns the order.

Look up the completed purchase and choose the item that needs to be returned. The eligibility window is measured from the recorded delivery date, and some items require case review. Keep the receipt and follow the packing instructions shown on the return request. Use the same order reference when checking follow-up.

## Exchanges

Ask for an exchange within 7 calendar days if the item is eligible. Replacements depend on available stock.

Use the account portal for a self-service change when the option is available. When contacting support about an existing purchase, keep the order reference handy and describe the outcome you need in a short message.

When requesting an exchange, state the preferred replacement or describe the issue with the item you received. Check whether that replacement is available before assuming it has been allocated. If a replacement is unavailable, support can explain the applicable return or refund options for the order.

## Damaged items

Report shipping damage within 48 hours of delivery. A human agent can request evidence through the ticket.


Use the order reference when filing a damage report and describe the condition that you observed when opening the parcel. Keep the item and packaging available while the case is reviewed. Provide photos through the support ticket if the reviewer requests them, and keep a copy of the ticket reference.
