# Password recovery

<!-- intents: recover_password -->

## Reset link

Request a reset link from the sign-in page. A password reset link expires after 15 minutes.

General policy applies across the fictional KharidiKart store. Check My Orders for details tied to a particular purchase. The demo displays order information only after selecting the account that owns the order.

Open the sign-in page yourself and choose the password reset option. Use the email attached to the account that owns your orders. After the page accepts a new password, return to sign-in and test access before attempting any purchase changes. A fresh reset request replaces an expired link.

## Resend

Check spam first and wait 2 minutes before requesting another reset email. The latest link supersedes older ones.

Use the account portal for a self-service change when the option is available. When contacting support about an existing purchase, keep the order reference handy and describe the outcome you need in a short message.

Look in spam, bulk mail and any inbox tab that filters automated messages. Check that the address you entered matches the account email. If several reset messages arrive together, open the newest one and close the older emails so you can identify which link you used.

## Credentials

Support can help with access using the registered email. Never share a password or a one-time code in chat.


If repeated requests fail, support can review the access issue through a ticket. Explain when you requested recovery and whether the form appeared to complete. Keep password text, verification links and one-time codes private. Use account settings to update contact details after you have regained access.
