# Privacy and data requests

<!-- intents:  -->

## Order privacy

Only the signed-in order owner can look up an order, invoice, or refund. Sharing an order reference does not grant access.

General policy applies across the fictional KharidiKart store. Check My Orders for details tied to a particular purchase. The demo displays order information only after selecting the account that owns the order.

An order number helps the owner identify a purchase after signing in. It does not serve as an authentication credential. Support will check the account associated with a request before sharing order details. A gift recipient who needs help can ask the purchaser to contact support using the original account.

## Request a copy

Ask for a copy of your data from signed-in privacy settings. Allow up to 30 calendar days for a response.

Use the account portal for a self-service change when the option is available. When contacting support about an existing purchase, keep the order reference handy and describe the outcome you need in a short message.

From privacy settings, specify the account and explain which personal information you need. Keep the request reference while the team processes it. If you also intend to close the account, collect the material you need before losing access to the account's support interface.

## Sensitive information

Support never requests passwords, verification codes or full card numbers. Keep those details out of every support message.


If you receive a message asking for credentials, start a new support request from the help area and describe where the message appeared. Do not copy credential values into the ticket. Share only the information needed to identify the incident and use account controls to review access when appropriate.
