# Contact hours

<!-- intents: contact_customer_service -->

## Human support

Human support is available Monday to Saturday from 09:00 to 18:00 IST.

General policy applies across the fictional KharidiKart store. Check My Orders for details tied to a particular purchase. The demo displays order information only after selecting the account that owns the order.

Use the human support option from the signed-in help area when you need an account-specific review. Keep the relevant reference ready to share after the team confirms the purchase. All published support hours use India Standard Time. A reply can depend on the current queue and the issue under review.

## Outside business hours

You can file a ticket at any hour. A person reviews it in the next available support window.

Use the account portal for a self-service change when the option is available. When contacting support about an existing purchase, keep the order reference handy and describe the outcome you need in a short message.

Submit a written ticket when the live support desk is closed. Describe the problem and note any useful context, such as the approximate time you saw the error. The help area keeps the ticket reference available so you can carry on when the next support window opens.

## Ticket details

Provide the order reference and a short description when contacting support. Acknowledge each case using its own ticket ID.


For order, refund or invoice questions, use the appropriate reference if you have it. When contacting support about a sign-in problem, explain which recovery steps you already tried. If a case is already open, reply using the existing ticket reference so the agent can see the previous updates.
