# Account creation

<!-- intents: create_account -->

## Sign-up

Create one account with your email from the registration page. Verify the address before placing an order.

General policy applies across the fictional KharidiKart store. Check My Orders for details tied to a particular purchase. The demo displays order information only after selecting the account that owns the order.

Enter an address you can access and review its spelling before submitting the sign-up form. When the verification message arrives, open the link from the service you just registered with and finish the sign-in step. Keep the same account when checking purchases or receipts, so the order history remains easy to find.

## Verification link

An account verification link expires after 30 minutes. Request a new link from the registration page.

Use the account portal for a self-service change when the option is available. When contacting support about an existing purchase, keep the order reference handy and describe the outcome you need in a short message.

An expired link goes back to the verification screen. Request a fresh message from that screen, then check spam and inbox filters if the email seems to be missing. When several messages arrive, try the most recent link first. Keep the verification link private while setting up your own account.

## Duplicate email

If an email is already registered, use sign-in or password recovery. Each email can be used for one account.


An existing account keeps its associated order and refund history. Use the password recovery page to restore access to that account. If registration continues to loop or the verification email never arrives, contact support with the registered email address and the approximate time of the attempt.
