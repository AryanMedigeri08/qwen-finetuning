# Shipping address changes

<!-- intents:  -->

## Before dispatch

You may update an address for a placed or packed order after confirming the new address. Update each affected order separately.

General policy applies across the fictional KharidiKart store. Check My Orders for details tied to a particular purchase. The demo displays order information only after selecting the account that owns the order.

Include the house or unit number, street, town and pin code in the proposed address. Review those details before confirming a change to the order. Reopen the order after the confirmation to verify that the update was applied. Use a separate request when more than one parcel requires attention.

## After dispatch

A shipped order's address is locked. Contact support with the order reference for assistance.

Use the account portal for a self-service change when the option is available. When contacting support about an existing purchase, keep the order reference handy and describe the outcome you need in a short message.

Once the carrier is handling the package, contact support with your order reference and the reason for the request. The team can review the available options from the delivery record. Changes to the address book do not change labels that are already attached to shipments.

## Saved addresses

Save up to 5 addresses in account settings. Changing a saved address leaves existing orders as they are.


Give saved addresses names that help you identify them during checkout. Check the destination for each order because the default address can change between purchases. Remove entries you no longer use so an old address is less likely to be selected for a future purchase.
