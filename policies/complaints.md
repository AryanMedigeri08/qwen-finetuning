# Complaints and escalation

<!-- intents:  -->

## File a complaint

Describe the problem to support and keep the ticket reference. We aim to acknowledge complaints within 1 working day.

General policy applies across the fictional KharidiKart store. Check My Orders for details tied to a particular purchase. The demo displays order information only after selecting the account that owns the order.

State what happened, the affected order reference and the resolution you are seeking. Attach information through a support ticket when it is needed to explain the issue, such as the time of a delivery problem. Keep the first ticket number so you can find the acknowledgement and any follow-up.

## Escalation

Ask for escalation using the existing ticket reference. A supervisor aims to review the case within 2 working days.

Use the account portal for a self-service change when the option is available. When contacting support about an existing purchase, keep the order reference handy and describe the outcome you need in a short message.

If an issue is unresolved and needs additional review, ask the team to escalate the existing case. Mention the most recent update and explain what remains open. The review window describes when a supervisor aims to assess the case, and individual cases may need more information before they can be closed.

## Keep context

Use one ticket per issue. Reply on the existing ticket to keep the case history together.


Keep messages about the same issue together to help the next reviewer understand the sequence of events. For a different purchase or a distinct payment problem, open a separate ticket so the records can be tracked separately. Check account messages for replies and reference the ticket when resuming the conversation.
